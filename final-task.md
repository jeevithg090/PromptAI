> 1. **PHASE F0 — prove that everything already built is actually good** (real verification, not checkbox faith — the audit that produced this file already found one regressed test suite, see F0.1).

> 3. **PHASE F2 — experience upgrades** identified from a full project review, each with an implementation plan.

The audit table below records the answer as of **2026-07-11**; the executing engineer must re-verify at execution time (grep the routes, open the UI) before writing code — if the feature has appeared since, convert the task into a review + gap-fill of the existing implementation instead of building a duplicate.

When outsourcing, feed the model the Global Context Block v2 + exactly one task prompt.
